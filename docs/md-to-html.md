# md-to-html

Markdown 파일을 독립형 HTML 페이지로 변환합니다.  
외부 의존성 없이 CSS/JS가 인라인으로 포함된 단일 `.html` 파일을 생성합니다.

변환 작업 전체를 서브에이전트가 수행하므로, 메인 세션 컨텍스트에는 HTML 본문이 쌓이지 않습니다.

## 언제 사용하나요?

- 계획 문서나 Spec을 시각적으로 보기 좋게 만들고 싶을 때
- Markdown을 웹페이지나 공유 문서로 변환할 때
- 외부 서버 없이 브라우저에서 바로 열 수 있는 문서가 필요할 때

## 트리거 문구

```
"MD를 HTML로 변환해줘"
"마크다운으로 웹페이지 만들어줘"
"이 MD 파일로 HTML 만들어줘"
"render this"
"make it look nice"
```

Markdown 내용을 직접 붙여넣어도 동작합니다.

## 실행 흐름

1. **입력·출력 경로 확정** — 파일 경로를 받으면 그대로 사용하고, 붙여넣은 내용이면 스크래치패드에 `.md`로 먼저 저장합니다. (서브에이전트는 대화 컨텍스트를 상속하지 않으므로 파일이 있어야 합니다.)
2. **서브에이전트 dispatch** — `general-purpose` 서브에이전트가 `frontend-design` 스킬을 로드하고, MD를 읽어 HTML을 작성해 저장합니다. 여러 파일이면 파일당 하나씩 병렬 실행합니다.
3. **결과 보고** — 메인 세션은 저장 경로와 한 문장 요약만 전달받아 사용자에게 알립니다.

후속 디자인 수정 요청은 같은 서브에이전트를 이어서 사용합니다 — HTML 컨텍스트가 그쪽에 남아 있습니다.

## 사용 예시

```
"docs/plan/task-payment-refund.md를 HTML로 변환해줘"
→ docs/plan/task-payment-refund.html 생성
```

## 출력 파일 특성

- 모든 CSS/JS 인라인 포함 (외부 CDN·폰트·이미지 없음)
- 헤딩, 리스트, 인용문, 코드 블록, 테이블, 링크, 이미지 모두 렌더링
- 원문 내용을 요약·생략하지 않고 전부 반영
- 파일 경로를 받은 경우 소스와 같은 디렉토리에 저장, 붙여넣은 경우 현재 작업 디렉토리에 저장 (스크래치패드에 남기지 않음)
- 브라우저에서 바로 열 수 있는 완전한 독립 파일
